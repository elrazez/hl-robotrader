4. **Control plane** in `liqfade/control/`: pydantic-typed command and response models for `status`, `pause`, `resume`, `flat`, `kill`, `reload_config`, `get_metrics`; a Unix-domain-socket server (newline-delimited JSON, `orjson`) that dispatches to a `ControlBackend` protocol; a `NoopBackend` that returns canned state so Telegram and the panel can be developed before the live loop exists; an async client; a `StateWriter` that atomically writes `data/state.json` every second (write temp file, `os.replace`) with a versioned schema (`schema_version`, `proc`, `ts_ms`, `feeds`, `positions`, `orders`, `risk`, `latency`, `universe`). Socket path from config, created with mode `0600`. Tests: client sends each command to a server running `NoopBackend` in-process and gets a typed response; `StateWriter` never leaves a partial file (test by reading concurrently in a loop).

5. **CLI** `liqfade` (typer or argparse, your call, keep it small) with subcommands `record`, `backfill`, `backtest`, `paper`, `testnet`, `live`, `panel`, `status`, `sync`, `config`. Build script writes to `liqfade/panel/static/`, FastAPI serves it. Commit the built bundle.
